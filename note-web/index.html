千千笔记

千千笔记是一款面向 iPhone 和 iPad 的手写笔记、PDF 批注与无限画布应用。它默认在设备本地保存笔记内容，不需要创建账号，适合课堂学习、会议记录、资料阅读、灵感整理和长期知识管理。

CopperNote is a handwriting, PDF annotation, and infinite canvas workspace for iPhone and iPad. It stores note content on device by default and does not require an account.

隐私政策了解千千笔记处理笔记、图片、PDF、录音和权限的方式。 支持与联系查看常见问题、反馈渠道和提交问题时需要提供的信息。 用户协议了解千千笔记的使用规则、责任范围和用户内容说明。

主要功能

  • Apple Pencil 或手指书写、荧光标注、橡皮和套索选择
  • 空白、横线、点阵、方格、康奈尔、计划、会议、阅读、数学和五线谱模板
  • PDF 导入、批注和 PDF 导出
  • 图片插入、拍照扫描、文本、形状和页面元素
  • 课堂、访谈和会议录音笔记
  • 笔记本、PDF、快速笔记、文件夹和无限画布文档库
  • 连续页面、缩略图侧栏、文档标签和自定义工具栏

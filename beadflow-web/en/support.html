Canvas and tools

The canvas will not pan

Select the Move tool and drag with one finger. Pinch to zoom while using any tool. Double-tap to fit, or use the zoom controls for precise adjustment. Drag the short handle at the top of the bottom tool panel; it snaps to collapsed, middle, and expanded heights.

Layer visibility or locking

Use the eye icon to show or hide a layer and the lock icon to prevent edits. Each layer has independent pixels, opacity, and ordering. Merge Down composites the active layer into the layer below it.

The brush does not draw a continuous line

Enable Continuous in the tool controls. Drag samples are then connected automatically. Brushes support sizes from 1–24 cells and round or square shapes. Locked layers reject strokes.

Generation and previews

A photo has the wrong orientation

The app normalizes image orientation before cropping and quantization. If a source file still behaves incorrectly, rotate it in Photos, save a copy, and import the copy.

Why is a template blank?

Current template cards render actual pattern data. If an older cached project remains empty, reopen the template and create a new editable copy.

Entering a very large size

Blank canvas, photo generation, and project size settings accept direct numeric input, plus step buttons and presets. Very large canvases use more memory; split work into boards and reduce auxiliary overlays when needed.

Projects, exports, and backup

Projects are stored in the app’s local container by default. Regularly export important work as a project file, PNG, PDF, or material list to a location you control. Export before uninstalling. The current version has no developer server that can recover a deleted local project.

If export fails, confirm the destination has free space, reduce export resolution, or paginate by board. Destinations in the system share sheet are provided by iOS and installed apps.

Changing language

Open My → Settings → Language and choose System, Simplified Chinese, or English. The interface refreshes immediately. Project names and text you entered are not automatically translated.

Report an issue

Open an issue in the project repository with the device model, iOS version, app version, reproduction steps, expected result, and actual result. Hide private photos, QR content, and project names before attaching screenshots.

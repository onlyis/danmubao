隐私政策

适用于快易翻（iTranslater）及其 Safari / Chromium Web Extension。最后更新：2026 年 9 月 21 日。

概要：快易翻不要求创建账号，也不以广告追踪为目的收集用户内容。为了完成用户主动触发或配置的翻译、OCR、文档和字幕功能，相关文本、图片、文档或音频片段可能发送给用户当前选择或自行配置的第三方服务。第三方服务将依据其各自的隐私政策处理数据。

1. 本政策适用范围

本政策说明快易翻在浏览器扩展、Safari Web Extension 及配套 containing app 中如何访问、处理和保存信息。扩展需要在网页中运行内容脚本，因此会申请网页访问权限；这些权限用于识别页面内容、执行翻译、显示双语结果以及响应用户启用的悬停、划词、输入框和字幕功能。

2. 我们处理的信息

类型处理方式
网页与选中文本在用户翻译网页、选中文本、悬停文本或使用侧边栏时读取相关文本。需要在线翻译时，内容会发送到当前选定的翻译服务。
输入框内容仅在用户启用并触发输入框翻译时读取当前输入内容，以生成译文；处理范围取决于用户当前操作的输入区域。
文档内容用户主动选择文件或提供文档 URL 后进行解析与翻译。支持 PDF、文本、Markdown、HTML、EPUB、字幕文件等。需要第三方翻译或文档服务时，相关内容会发送到用户选择的服务。
图片与 OCR用户选择图片、区域或截图后，可优先使用浏览器提供的本地文字识别能力；如果用户配置并选择自定义 OCR / 图片渲染服务，相应图片数据会发送至该服务。
视频字幕与音频页面已有字幕可直接读取并翻译。只有在用户主动启用需要语音识别的 AI 字幕流程时，扩展才会使用标签页音频捕获能力，并按用户配置将音频片段发送至相应 ASR 服务。
设置、历史、收藏与术语主要保存在浏览器扩展本地存储中，用于恢复设置、展示历史、收藏词和术语。用户可在扩展中清除这些数据。
API Key 与自定义端点由用户自行填写并保存在本地扩展存储中，用于访问用户选定的翻译 / AI / OCR / ASR 服务。普通非敏感设置同步不会包含这些秘密字段。

3. 第三方翻译与 AI 服务

快易翻提供多个可选翻译入口，包括浏览器内置翻译能力、MyMemory、Google、DeepL、Microsoft、百度以及用户自行配置的 AI / 自定义兼容服务。具体可用服务取决于版本、浏览器环境和用户配置。使用在线服务时，待翻译文本以及实现该功能所必需的上下文可能被发送给该服务。我们不控制第三方服务的数据保存策略、训练政策或跨境传输安排；用户应同时阅读并遵守所选服务的隐私政策与条款。

4. 本地存储与 Chrome Sync

扩展使用浏览器的 storage 能力保存设置、收藏词、历史记录、术语和必要的缓存。非敏感设置同步与词库备份不是强制功能；只有在用户启用相关同步、恢复或备份操作时，数据才会通过浏览器提供的 Chrome Sync 机制写入用户的浏览器账号同步空间。Chrome Sync 由 Google / 浏览器提供方按照其自身政策处理。

5. 缓存与临时数据

为了提高翻译速度，部分翻译结果可能保存在会话或本地缓存中；区域截图、处理中间结果也可能在浏览器提供的缓存区域中短暂保存。用户可以通过清理扩展数据、浏览器站点 / 扩展数据或卸载扩展删除本地数据。

6. 权限说明

  • activeTab / tabs / scripting / <all_urls>：在用户访问的网页中运行翻译功能、读取当前页面必要内容并呈现结果。
  • storage：保存设置、缓存、收藏、历史和术语。
  • sidePanel：提供侧边栏翻译工作区。
  • contextMenus / commands：提供右键菜单和快捷键翻译入口。
  • offscreen / tabCapture：仅在需要后台媒体处理或用户主动启用音频字幕流程时使用。

7. 我们不会做的事情

  • 不要求注册快易翻账号。
  • 不出售用户的个人数据。
  • 不以广告定向或跨站行为画像为目的收集网页内容。
  • 不会在用户未配置相关在线功能时主动将 API Key 公开给其他用户。

8. 数据控制与删除

用户可以在扩展设置中清除历史、收藏、缓存和相关配置，也可以在浏览器的扩展管理页面移除扩展并删除扩展本地数据。对于已经发送至第三方翻译 / AI / OCR / ASR 服务的数据，删除请求需依据对应第三方服务的政策向其提出。

9. 儿童隐私

快易翻是通用生产力工具，不以儿童为目标用户，也不会主动要求提供年龄、真实姓名或社交资料。如果监护人认为未成年人通过某个第三方服务提交了不适当的信息，应同时联系该第三方服务与我们。

10. 政策变更

如果功能、权限或数据处理方式发生实质变化，我们会更新本页面并修改“最后更新”日期。重大变化会尽可能在产品更新说明或支持页面中提示。
